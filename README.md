# SetLoop

Interval timer for iPhone: build workouts from steps, blocks and sets — from a simple Tabata to multi-block circuits. Live Activity on the lock screen and in the Dynamic Island, sound and voice cues, workout history.

**Status:** in development, not yet on the App Store.

- iOS 17+, iPhone, Russian and English
- Free, no ads, no data collected
