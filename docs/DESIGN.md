# SetLoop — базовый дизайн

> Подтверждённые дизайн-решения. Функциональные решения лежат в [SPEC.md](SPEC.md).

## Решения

- **V1. Стиль экрана тренировки: насыщенный.**
  - Яркая заливка цветом шага, белые цифры и элементы.
  - Кольцо прогресса белое на полупрозрачном белом.
  - Центральная кнопка — белый круг с иконкой цвета шага.
  - Стиль один и тот же в светлой и тёмной теме: экран тренировки от темы не зависит.
  - Требование к цветам шагов: контраст белого текста не ниже 3:1 (WCAG для крупного текста).
- **V2. Типы шагов и цвета** (на всех белый текст). Шесть фиксированных типов, цвета по умолчанию:

  | Тип | Цвет | Контраст с белым | В истории считается как |
  |---|---|---|---|
  | Подготовка | `#5B6470` графит | 6.0 | не учитывается |
  | Работа A | `#E8452C` красно-оранжевый | 4.0 | работа |
  | Работа B | `#9C2BB0` пурпурный | 6.2 | работа |
  | Работа C | `#B86200` янтарный | 4.4 | работа |
  | Отдых | `#1E8E52` зелёный | 4.2 | отдых |
  | Заминка | `#5B6470` графит | 6.0 | не учитывается |

  - Подготовка и заминка одного цвета по умолчанию: они не соседствуют. В настройках их можно развести.
  - Типа «Свой» нет.
  - В листе шага тип выбирается из короткого списка с цветными метками.
  - Цвет каждого типа меняется в Настройках → «Цвета шагов» и сразу применяется ко всем таймерам.
  - Палитра для выбора (12 цветов, все с контрастом белого ≥ 3.7): Красный `#E8452C`, Розовый `#D63C7E`, Пурпурный `#9C2BB0`, Фиолетовый `#7B4FD6`, Индиго `#4B55C9`, Синий `#2F6BDB`, Морской `#0E7C9E`, Бирюзовый `#0F8A8A`, Зелёный `#1E8E52`, Оливковый `#5F8F1A`, Янтарный `#B86200`, Графит `#5B6470`.
- **V3. Шрифты.**
  - Цифры таймера и крупные заголовки на экране тренировки: **SF Pro Rounded**, полужирный или жирный, цифры одинаковой ширины.
  - Остальной интерфейс: системный SF Pro с поддержкой Dynamic Type.
- **V4. Главный экран: карточки с цветной полосой-превью.** Полоса строится автоматически, уровень детализации выбирается по порогу (сейчас 24 сегмента):
  1. Вся тренировка: все сегменты ≤ порога.
  2. Один сет: сетов > 1 и один сет ≤ порога.
  3. Один цикл каждого блока с подписью «×N»: сумма шагов в блоках ≤ порога.
  4. Только блоки: каждый блок одним сегментом цвета самого длинного шага, подпись «×N».

  Ещё правила:
  - Минимальная ширина сегмента 3 pt. Блоки на уровнях 3–4 делят ширину поровну.
  - Порог — константа в коде, а не пользовательская настройка. Подбирается по факту на устройстве.
  - Новые ограничения конструктора: **до 10 блоков в таймере, до 30 шагов в блоке** (дополняют D18 в SPEC).
  - Статус: стартовые значения, пересмотреть после первых тестов на устройстве.
- **V5. Экран итогов.**
  - Галочка, фактическое время (SF Pro Rounded), статус-бейдж.
  - Три метрики: работа / отдых / «шагов N из M».
  - Полоса пройденного: выполненные шаги яркие, пропущенные бледные (25%).
  - Поля «Название» и «Описание».
  - Главная кнопка «Сохранить», текстовая кнопка «Не сохранять».
- **V6. История.**
  - Заголовок, две метрики недели (тренировок, время).
  - Записи по дням: название, время начала, длительность, полоса пройденного. У досрочно завершённых подпись «Частично».
  - Тап по записи открывает детали.
  - Справа вверху «Выбрать»: отметки у строк, слева «Выбрать все», внизу «Удалить (N)». Так же устроен список таймеров.
- **V7. Единая типографика.** Используем только системные текстовые стили iOS (Dynamic Type), без произвольных размеров. Размеры ниже — значения по умолчанию на iPhone:

  | Роль | Стиль iOS | Размер, pt |
  |---|---|---|
  | Крупный заголовок экрана (Таймеры, История, Настройки) | Large Title | 34 |
  | Заголовок в панели навигации | Headline | 17 semibold |
  | Текст строк, значения, кнопки | Body | 17 |
  | Вторичный текст в карточках (длительность, структура) | Subheadline | 15 |
  | Заголовки секций, подписи под группами | Footnote | 13 |
  | Подписи вкладок, «×N» над полосой | Caption 2 | 11 |
  | Цифры таймера | SF Pro Rounded, своя шкала (не Dynamic Type) | ~96 на экране тренировки |

  Ещё правила:
  - Высота строки списка не меньше 44 pt. Длинные подписи переносятся на вторую строку, а не обрезаются.
  - Длинные экраны прокручиваются. Крупный заголовок сжимается в панель навигации.
  - Панель навигации вложенного экрана — одна строка под строкой состояния: «‹ Назад» слева, заголовок по центру.
- **V8. Настройки.** Группы: Тренировка / Звук и вибрация / Оформление / О приложении. «Цвета шагов» — вложенный экран: палитра раскрывается в строке типа, ниже предпросмотр полосы и «Сбросить по умолчанию». Цвет отдыха нельзя выбрать ни для одной работы, и наоборот.
- **V9. Предпросмотр таймера** (тап по карточке).
  - Панель навигации: «‹ Таймеры», справа ✎ (редактор) и ⋯ (Изменить / Дублировать / Удалить с подтверждением).
  - Крупный заголовок — название, под ним строка структуры («2 блока · 3 сета · 33 шага»).
  - Карточка сводки: общее время (SF Pro Rounded), полоса по правилам V4, три метрики: Работа / Отдых / Прочее (подготовка и заминка).
  - Структура только для чтения: подготовка, сеты с отдыхом, блоки «×N», шаги с отступом и цветной меткой. Прокручивается.
  - Кнопка «Старт» закреплена внизу.
  - Строки «Последний раз» нет, это есть в Истории.
- **V11. Редактор таймера** (лист; «+», «Изменить», ✎ в предпросмотре).
  - Сверху поле названия; пустое при сохранении становится «Таймер».
  - Секция «Общее»: подготовка (или «Добавить подготовку»), сеты «× N» со степпером, отдых между сетами при N > 1.
  - Секция на каждый блок: «Циклы × N» со степпером, шаги (цветная метка, название, длительность серым), «Добавить шаг». В заголовке ⋯: Дублировать блок / Удалить блок. Ниже «Добавить блок».
  - Секция «Финиш»: заминка и «Пропускать последний отдых».
  - Внизу закреплены: общее время, полоса по V4, «Выбрать шаги» — режим с кружками выбора только у шагов и ручками перетаскивания, кнопка «Объединить в блок» (D2).
  - Тап по шагу открывает лист шага: название, список типов с меткой (скрыт у подготовки и заминки), колёса минут и секунд. Новый шаг — «Отмена», существующий — «Удалить» с подтверждением.
  - «Отмена» при изменениях спрашивает, отбросить ли их; свайп вниз при изменениях заблокирован.
- **V10. Live Activity.**
  - Экран блокировки: плашка залита цветом текущего шага, белый текст.
  - Состав: название шага с иконкой, «SetLoop · название таймера», цифры оставшегося времени (SF Pro Rounded), «Цикл · Сет», «Далее: …», кнопки «Пропустить» и «Пауза», прогресс шага.
  - Dynamic Island (всегда чёрный):
    - свёрнутый — кольцо прогресса цвета шага и время;
    - минимальный — только кольцо;
    - развёрнутый — название, время, счётчики, кнопки.
  - На чёрном фоне цвет шага осветляется для читаемости текста (например, `#E8452C` → `#FF6B52`).
