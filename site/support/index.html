Common questions (iPhone)

I don't hear the sounds

With the Silent switch on, signals are muted. Turn on Ignore Silent Mode in Settings → Sound and Haptics. Also check that a sound set is selected and the volume is up.

The timer stops changing on the Lock Screen

SetLoop keeps running in the background while sounds or voice prompts are on. If both are off, iOS pauses the app when the screen locks and steps change only when you open it again.

Occasionally iOS delays Lock Screen updates during a long workout; the timer inside the app stays correct and catches up when you open it.

My music gets quieter

During signals SetLoop lowers other audio for a moment so you can hear them. While the screen is locked music may stay a bit quieter until you return to the app.

The timer isn't on the Lock Screen

Check Show on Lock Screen in SetLoop settings and that Live Activities are allowed for SetLoop in the iOS Settings app.

How do I move my timers to a new iPhone?

Timers and history are part of your device backup: restore the new iPhone from an iCloud or computer backup. Sync between devices is planned for a future version.

Android

The timer stops when the screen is off or the app is in the background

Some phones close background apps to save battery. SetLoop runs a workout as a foreground service with a notification, but a strict battery mode can still stop it. Set the battery option for SetLoop to No restrictions:

  • Any Android: Settings → Apps → SetLoop → Battery → Unrestricted (or "Don't optimize").
  • Xiaomi / Redmi / POCO (HyperOS, MIUI): Settings → Apps → Manage apps → SetLoop → Battery saver → No restrictions. Also turn on Autostart for SetLoop.
  • Huawei / Honor: Settings → Battery → App launch → SetLoop → switch to Manage manually and allow Auto-launch, Secondary launch and Run in background.
  • Samsung (One UI): Settings → Apps → SetLoop → Battery → Unrestricted. Also remove SetLoop from Settings → Battery → Background usage limits → Sleeping apps.

Menu names differ between versions. The app warns you before a workout if the battery setting is "Restricted". See also dontkillmyapp.com for per-maker guides.

There is no countdown notification

On Android 13 and newer SetLoop asks for the notification permission. If you declined it, open Settings → Apps → SetLoop → Notifications and allow them. The permission is used only to show the workout countdown with Pause and Skip. Also check that the "Show on Lock Screen" setting in SetLoop is on if you want to see it on a locked phone.

I can't install the APK

Allow installing apps from your browser or file manager (Settings → Apps → Special access → Install unknown apps), then open the file again. The SHA-256 checksum is on the release page. The app needs Android 8.0 or newer.

Where do I report an Android bug?

Open an issue in the Android repository or write to @setnewloop in Telegram. Please name the phone model, maker and Android version.

Частые вопросы (iPhone)

Не слышно звуков

Когда включён переключатель «Бесшумно», сигналы молчат. Включите Игнорировать беззвучный режим в «Настройки» → «Звук и вибрация». Также проверьте, что выбран набор звуков и громкость не на нуле.

Таймер на экране блокировки перестаёт меняться

SetLoop работает в фоне, пока включены звуки или голосовые подсказки. Если выключено и то и другое, iOS приостанавливает приложение при блокировке, и шаги меняются, только когда вы его открываете.

Иногда на длинной тренировке iOS задерживает обновления экрана блокировки; таймер в самом приложении идёт верно и догоняет, когда вы его открываете.

Музыка становится тише

Во время сигналов SetLoop ненадолго приглушает другой звук, чтобы их было слышно. Пока экран заблокирован, музыка может оставаться чуть тише до возвращения в приложение.

Таймера нет на экране блокировки

Проверьте Показывать на экране блокировки в настройках SetLoop и что Live Activities разрешены для SetLoop в приложении «Настройки» iOS.

Как перенести таймеры на новый iPhone?

Таймеры и история входят в резервную копию устройства: восстановите новый iPhone из копии iCloud или компьютера. Синхронизация между устройствами запланирована в одной из следующих версий.

Android

Таймер останавливается при выключенном экране или в фоне

Некоторые телефоны закрывают фоновые приложения, чтобы экономить заряд. SetLoop ведёт тренировку как служба переднего плана с уведомлением, но строгий режим батареи всё равно может её остановить. Установите для SetLoop режим батареи Без ограничений:

  • Любой Android: «Настройки» → «Приложения» → SetLoop → «Батарея» → «Без ограничений» (или «Не оптимизировать»).
  • Xiaomi / Redmi / POCO (HyperOS, MIUI): «Настройки» → «Приложения» → «Все приложения» → SetLoop → «Контроль активности» (или «Экономия заряда») → «Нет ограничений». Также включите «Автозапуск» для SetLoop.
  • Huawei / Honor: «Настройки» → «Батарея» → «Запуск приложений» → SetLoop → переключите на «Управлять вручную» и разрешите автозапуск, косвенный запуск и работу в фоновом режиме.
  • Samsung (One UI): «Настройки» → «Приложения» → SetLoop → «Батарея» → «Без ограничений». Также уберите SetLoop из «Настройки» → «Батарея» → «Ограничения фоновой работы» → «Неиспользуемые приложения» (спящие).

Названия пунктов зависят от версии прошивки. Перед тренировкой приложение предупредит, если для него выбран режим «Ограничено». Руководства по производителям — на dontkillmyapp.com.

Нет уведомления с отсчётом

На Android 13 и новее SetLoop запрашивает разрешение на уведомления. Если вы отказали, откройте «Настройки» → «Приложения» → SetLoop → «Уведомления» и разрешите их. Разрешение нужно только для показа отсчёта тренировки с кнопками паузы и пропуска. Чтобы видеть его на заблокированном телефоне, также проверьте, что в настройках SetLoop включено «Показывать на экране блокировки».

Не получается установить APK

Разрешите установку приложений из вашего браузера или файлового менеджера («Настройки» → «Приложения» → «Особый доступ» → «Установка неизвестных приложений») и откройте файл снова. Контрольная сумма SHA-256 указана на странице релиза. Нужен Android 8.0 или новее.
